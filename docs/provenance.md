# Provenance and claim boundary

This independent portfolio project was built for Vedant Thaker with AI-assisted implementation, documentation, and review. The simulator, estimator implementation, integration, tests, and reports were created for this repository. It is new work, not a reconstruction of an employer system.

Technical themes align with production ML and marketplace decision engineering. A supplied practice resume and the [Instacart Senior Machine Learning Engineer, Fulfillment posting](https://www.instacart.careers/job?gh_jid=8240305) helped choose the scope. They are not data sources or verification of historical accomplishments. No claim in this repository attributes these results to Instacart, CSAA, Ace, Rapido, or any client.

The value of a policy, the confidence interval, the overlap diagnostics, and model error all refer to a single seeded synthetic experiment. The oracle is available only because this is a simulator. There is no cloud deployment, paid model/API call, real marketplace trial, external performance measurement, or claim of human-only authorship.

Research references inform estimator definitions. No third-party implementation was copied. Dependencies retain their own licenses; original repository code is MIT licensed.
